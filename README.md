# RTR Sponsors

This repository contains configuration and documentation for Goldie, the
creative agent used to support production, marketing, analytics, and client
operations workflows.

## Goldie skills

Goldie's skill registry lives at:

- `goldie/skills.json`

Supporting documentation and CLI utilities live at:

- `docs/goldie-skills.md`
- `scripts/goldie_skills.py`

Validate the registry:

```bash
python scripts/goldie_skills.py validate
```

List available skills:

```bash
python scripts/goldie_skills.py list
```

Look up public GitHub examples for new agent skills:

```bash
python scripts/goldie_skills.py search-github "ai agent skills"
```

Goldie's current skills include Final Cut Pro, Premiere Pro, DaVinci Resolve,
Photoshop, Higgsfield plug-in generation, Gmail, Google Drive, app creation,
social media analytics, paid ads management, analytics reports, marketing
strategy, price decks, invoice management, offer emails, and GitHub skill
research.
